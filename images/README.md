# Product images

Drop your jersey photos here using this naming convention. The site
auto-loads any photos that exist and falls back to the SVG illustration
if a file is missing.

## Folder layout

```
images/
├── jerseys/
│   ├── arg-home/      ← Argentina Home Kit
│   │   ├── 1.jpg      ← Primary (front) — used on the jersey card
│   │   ├── 2.jpg      ← Back view
│   │   ├── 3.jpg      ← Detail / fabric close-up
│   │   └── 4.jpg      ← Lifestyle (worn by a model)
│   ├── arg-away/
│   ├── bra-home/
│   ├── bra-away/
│   ├── fra-home/
│   ├── fra-away/
│   ├── esp-home/
│   └── esp-away/
├── hero/              ← Optional hero background asset
│   └── poster.jpg
└── about/             ← About-page photos
    └── store.jpg
```

## Photo specs (recommended)

- **Format:** JPG (best balance of quality + size). PNG only if you need transparency.
- **Size:** 1200×1200 px square, max 300 KB per file (use [tinypng.com](https://tinypng.com) to compress).
- **Background:** plain white or product-shot grey for the first 3 photos; lifestyle shot can be on-location.
- **Quantity:** up to 4 photos per jersey. 1 is enough to get started.

## What to shoot per jersey

| Slot | Shot | Purpose |
|------|------|---------|
| 1.jpg | Front, flat or on hanger | Card thumbnail + quick view main |
| 2.jpg | Back (with name/number) | Show customization potential |
| 3.jpg | Fabric/stitching close-up | Quality proof |
| 4.jpg | Worn by model in motion | Lifestyle / conversion |

When new photos go in, the site picks them up on the next page load. No code changes needed.
